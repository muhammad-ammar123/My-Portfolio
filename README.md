# M. Ammar Portfolio

A responsive personal portfolio built with plain HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a modern browser. No build step or package installation is required.

## Customize

- GitHub and LinkedIn links are included in the hero, contact section, and footer.
- Add verified repository or live-demo URLs to the project cards when ready.
- Contact details include the provided email, phone number, Islamabad location, GitHub, and LinkedIn.
- Theme preference is saved in browser local storage.

## Structure

```text
index.html
README.md
style.css
script.js
```

All four files are in the same folder. The HTML links directly to `style.css` and `script.js`.
